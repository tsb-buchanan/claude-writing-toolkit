# Writing toolkit for Claude

Skills for Claude that help one writer turn a rough draft of a thesis, report or paper into a clear one, with every change shown for approval first.
It is for anyone who writes long documents, on claude.ai or in Claude Code: a PhD student with a thesis, or a business writer with a report.
On claude.ai: add `tsb-buchanan/claude-writing-toolkit` under Customize, Plugins, Add marketplace, or upload the skill zips from [Releases](../../releases), then follow [docs/web-guide.md](docs/web-guide.md).
In Claude Code: `/plugin marketplace add tsb-buchanan/claude-writing-toolkit`, then `/plugin install writing-toolkit@writing-toolkit`, as [docs/claude-code-guide.md](docs/claude-code-guide.md) shows.
