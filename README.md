# Writing toolkit for Claude

Skills for Claude that help one writer turn a rough draft of a thesis, report or paper into a clear one, with every change shown for approval first.
It is for anyone who writes long documents, on claude.ai or in Claude Code: a PhD student with a thesis, or a business writer with a report.
On claude.ai: download the skill zips and web-guide.docx from [Releases](../../releases), then follow the guide (also in [docs/web-guide.md](docs/web-guide.md)).
In Claude Code: unzip writing-toolkit-skills.zip into .claude/skills/ and type /doc-setup, as [docs/claude-code-guide.md](docs/claude-code-guide.md) shows.
