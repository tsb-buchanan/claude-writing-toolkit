# Thesis questions

Add these to round 3 in thesis mode. Put your proposal, or the default, next to each.

1. Papers: is any chapter based on a paper? For each one, is it submitted or published, and what may change in it: none, light or full? Default: light for a published paper, full for a submitted one. Light means voice, spelling, dashes, number format and banned words only.
2. A part of a chapter taken from a paper: the writer marks it in the file as keep light. In LaTeX, that is a line "% keep light" before it and a line "% end keep" after it. Offer to show where the marks go. Never add the marks yourself.
3. Contribution statements: should a chapter based on a co-authored paper say who did what? Default: yes.
4. Notation source: which chapter sets the symbols? Or should the thesis keep a symbol table? Default: the symbol table.
5. Symbol definitions: define each symbol at its first use in each chapter, or once in the thesis? Default: each chapter, because examiners often read one chapter on its own.
6. The next milestone, for example "committee draft". There is no default.
7. Claude Code only: confirm the file for each chapter.

Write the answers into the parts list (paper and passes) and into the Thesis part of the profile.
